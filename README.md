# PHP Bulk Barcode Generator & Validator

This repository contains a lightweight PHP utility for validating EAN-13 and Code-128 barcode formats prior to printing. 

Validating your data format is critical when processing massive warehouse manifests to avoid thermal printer errors and scannability issues.
